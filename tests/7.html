Задача 1 (5 баллов)

Определение субградиента и субдифференциала

а) (3 балла) Дайте определение субградиента g \in \mathbb{R}^n функции f : \mathbb{R}^n \to \mathbb{R} в точке x_0. Запишите условие глобальной субградиентной недооценки.

б) (2 балла) Поясните: если f дифференцируема в x_0, что является единственным субградиентом?

Ответ

а) Вектор g \in \mathbb{R}^n называется субградиентом функции f в точке x_0, если для всех x \in \mathbb{R}^n: f(x) \geq f(x_0) + \langle g,\, x - x_0 \rangle.

Субдифференциал \partial f(x_0) = \{g \in \mathbb{R}^n : f(x) \geq f(x_0) + \langle g, x - x_0\rangle\ \forall x\}.

б) Если f дифференцируема в x_0: \partial f(x_0) = \{\nabla f(x_0)\}. Субградиент единственен и совпадает с обычным градиентом.

Задача 2 (4 балла)

Субградиент функции модуля и L1-нормы

а) (2 балла) Найдите \partial |x| для x \in \mathbb{R} (покоординатно).

б) (2 балла) Найдите \partial \|w\|_1 для w \in \mathbb{R}^d. Запишите покоординатно.

Ответ

а) Функция f(x) = |x|: \partial|x| = \begin{cases} \{1\}, & x > 0 \\ \{-1\}, & x < 0 \\ [-1, 1], & x = 0 \end{cases}

б) \|w\|_1 = \sum_{j=1}^d |w_j| — покоординатная сепарабельная функция. Субдифференциал: \partial\|w\|_1 = \prod_{j=1}^d \partial|w_j|, где \partial|w_j| = \operatorname{sign}(w_j) при w_j \neq 0 и \partial|w_j| = [-1, 1] при w_j = 0.

Формально: g \in \partial\|w\|_1 тогда и только тогда, когда g_j = \operatorname{sign}(w_j) для w_j \neq 0 и |g_j| \leq 1 для w_j = 0.

Задача 3 (5 баллов)

Субградиентный метод: шаг и обновление

Рассмотрим задачу \min_{w \in \mathbb{R}^d} f(w) при f выпуклой (возможно, негладкой).

Субградиентный метод (шаг \alpha_k > 0): w_{k+1} = w_k - \alpha_k\, g_k, \quad g_k \in \partial f(w_k).

а) (3 балла) Докажите следующее неравенство: \|w_{k+1} - w^*\|^2 \leq \|w_k - w^*\|^2 - 2\alpha_k(f(w_k) - f^*) + \alpha_k^2\|g_k\|^2.

б) (2 балла) Откуда это неравенство говорит о том, что при слишком большом шаге метод может расходиться?

Ответ

а) Раскроем: \begin{align*} \|w_{k+1} - w^*\|^2 &= \|w_k - \alpha_k g_k - w^*\|^2 \\ &= \|w_k - w^*\|^2 - 2\alpha_k \langle g_k, w_k - w^*\rangle + \alpha_k^2\|g_k\|^2. \end{align*}

Из определения субградиента: f(w^*) \geq f(w_k) + \langle g_k, w^* - w_k\rangle, т.е.: \langle g_k, w_k - w^* \rangle \geq f(w_k) - f(w^*) = f(w_k) - f^*.

Подставляем: \|w_{k+1} - w^*\|^2 \leq \|w_k - w^*\|^2 - 2\alpha_k(f(w_k) - f^*) + \alpha_k^2\|g_k\|^2. \;\square

б) Если \alpha_k^2\|g_k\|^2 > 2\alpha_k(f(w_k) - f^*), т.е. \alpha_k > \frac{2(f(w_k)-f^*)}{\|g_k\|^2}, то \|w_{k+1} - w^*\| > \|w_k - w^*\| — расстояние до оптимума увеличивается.

Задача 4 (5 баллов)

Сходимость субградиентного метода: постоянный шаг

Предположим: f — выпуклая, \|g_k\| \leq G для всех k. Используем постоянный шаг \alpha_k = \alpha.

а) (4 балла) Просуммируйте неравенство из Задачи 3 по k = 0, \ldots, K-1 и получите оценку: \min_{k \leq K-1} f(w_k) - f^* \;\leq\; \frac{\|w_0 - w^*\|^2}{2\alpha K} + \frac{\alpha G^2}{2}.

б) (1 балл) При каком \alpha оценка минимальна по \alpha? Чему равна оптимальная оценка?

Ответ

а) Из Задачи 3, суммируем: \sum_{k=0}^{K-1} \|w_{k+1} - w^*\|^2 \leq \sum_{k=0}^{K-1}\|w_k - w^*\|^2 - 2\alpha\sum_{k=0}^{K-1}(f(w_k)-f^*) + K\alpha^2 G^2.

Телескопируем: 2\alpha\sum_{k=0}^{K-1}(f(w_k)-f^*) \leq \|w_0 - w^*\|^2 - \|w_K - w^*\|^2 + K\alpha^2 G^2 \leq \|w_0 - w^*\|^2 + K\alpha^2 G^2.

Разделим на 2\alpha K: \frac{1}{K}\sum_{k=0}^{K-1}(f(w_k)-f^*) \leq \frac{\|w_0-w^*\|^2}{2\alpha K} + \frac{\alpha G^2}{2}.

Поскольку \min_{k} f(w_k) \leq \frac{1}{K}\sum_k f(w_k): \min_{k \leq K-1} f(w_k) - f^* \leq \frac{\|w_0-w^*\|^2}{2\alpha K} + \frac{\alpha G^2}{2}. \;\square

б) Минимизируем по \alpha: взять производную \frac{d}{d\alpha}\left(\frac{R^2}{2\alpha K} + \frac{\alpha G^2}{2}\right) = 0, где R = \|w_0 - w^*\|.

\alpha^* = \frac{R}{G\sqrt{K}}.

Оптимальная оценка: \dfrac{RG}{\sqrt{K}} — скорость сходимости O(1/\sqrt{K}).

Задача 5 (5 баллов)

Субградиентный метод для LASSO

Рассмотрим задачу: \min_{w \in \mathbb{R}^d} f(w) = \frac{1}{2n}\|Xw - y\|^2 + \lambda\|w\|_1.

а) (2 балла) Запишите субградиент g \in \partial f(w) через \nabla(\text{гладкая часть}) и \partial\|w\|_1.

б) (3 балла) Почему для LASSO лучше использовать проксимальный градиентный метод (ISTA), а не субградиентный? Сравните скорости сходимости.

Ответ

а) Функционал f(w) = f_{\text{sm}}(w) + \lambda\|w\|_1, где f_{\text{sm}}(w) = \frac{1}{2n}\|Xw-y\|^2 гладкая.

По правилу субдифференциального счёта: \partial f(w) = \nabla f_{\text{sm}}(w) + \lambda\,\partial\|w\|_1 = \frac{X^\top(Xw-y)}{n} + \lambda\,\partial\|w\|_1.

Один конкретный субградиент: g = \frac{X^\top(Xw-y)}{n} + \lambda\,s, где s_j = \operatorname{sign}(w_j) (|s_j| \leq 1 при w_j = 0).

б) Сравнение:

Метод Скорость Требование
Субградиентный O(1/\sqrt{K}) Только выпуклость
ISTA (прокс. GD) O(1/K) f_{\text{sm}} — L-гладкая
FISTA O(1/K^2) f_{\text{sm}} — L-гладкая

ISTA использует структуру задачи: применяет градиент только к гладкой части f_{\text{sm}}, а негладкую часть \lambda\|w\|_1 обрабатывает через проксимальный оператор (soft-thresholding). Это даёт на порядок лучшую сходимость O(1/K) против O(1/\sqrt{K}).

Задача 6 (5 баллов)

Hinge loss и SVM: субградиент

Рассмотрим функцию hinge loss (потери для SVM): f(w) = \frac{1}{n}\sum_{i=1}^n \max\bigl(0,\; 1 - y_i \langle w, x_i\rangle\bigr) + \frac{\mu}{2}\|w\|^2, где y_i \in \{-1, +1\}, x_i \in \mathbb{R}^d.

а) (3 балла) Найдите субградиент g \in \partial\,\max(0, 1-z) для z \in \mathbb{R}. Запишите субградиент всей функции f(w).

б) (2 балла) В чём принципиальное отличие от задачи логистической регрессии (которая гладкая)? Почему разрывность субградиента важна для разреженности решения в SVM?

Ответ

а) Для h(z) = \max(0, 1-z): \partial h(z) = \begin{cases} \{0\}, & z > 1 \\ \{-1\}, & z < 1 \\ [-1, 0], & z = 1 \end{cases}

Субградиент потерь по w (через правило цепочки): g_i(w) = \begin{cases} 0, & y_i\langle w, x_i\rangle > 1 \\ -y_i x_i, & y_i\langle w, x_i\rangle < 1 \\ \text{convex combination}, & y_i\langle w, x_i\rangle = 1 \end{cases}

Полный субградиент f(w): g = \frac{1}{n}\sum_{i: y_i\langle w,x_i\rangle < 1} (-y_i x_i) + \mu\, w.

(Суммирование только по нарушающим примерам — support vectors.)

б) Логистическая регрессия использует \log(1 + e^{-yz}) — гладкая функция, все объекты вносят вклад в градиент. SVM hinge loss — кусочно-линейная: объекты с y_i\langle w,x_i\rangle > 1 (правильно классифицированные с запасом) вносят нулевой субградиент. Это создаёт естественную разреженность в пространстве объектов (только опорные векторы определяют границу) — один из ключевых принципов SVM.

Задача 7 (6 баллов)

Убывающий шаг и условие Polyak

а) (3 балла) Для субградиентного метода с убывающим шагом \alpha_k = c/\sqrt{k+1} покажите, что: \sum_{k=0}^\infty \alpha_k = \infty, \quad \sum_{k=0}^\infty \alpha_k^2 < \infty.

Объясните, почему это условие необходимо для сходимости.

б) (3 балла) Шаг Полиака (Polyak step): \alpha_k = \dfrac{f(w_k) - f^*}{\|g_k\|^2} (предполагается, что f^* известно).

Покажите, что с шагом Полиака расстояние до оптимума строго убывает: \|w_{k+1} - w^*\|^2 \leq \|w_k - w^*\|^2 - \frac{(f(w_k) - f^*)^2}{\|g_k\|^2}.

Ответ

а) При \alpha_k = c/\sqrt{k+1}: \sum_{k=0}^K \alpha_k = c\sum_{k=0}^K \frac{1}{\sqrt{k+1}} \geq c\int_0^{K+1}\frac{dk}{\sqrt{k+1}} = 2c\sqrt{K+2} \to \infty.

\sum_{k=0}^\infty \alpha_k^2 = c^2\sum_{k=0}^\infty \frac{1}{k+1} \cdot \frac{1}{1} \to \ldots

Подождём: \alpha_k^2 = c^2/(k+1), поэтому \sum \alpha_k^2 = c^2\sum 1/(k+1) = +\infty.

Исправление: используем \alpha_k = c/(k+1) (гармонический ряд). Для \alpha_k = c/\sqrt{k+1}: \sum \alpha_k^2 = c^2\sum 1/(k+1) \to \infty. Это не подходит!

Правильный выбор: \alpha_k = c/\sqrt{k+1} даёт: - \sum \alpha_k = \infty ✓ (ряд \sum 1/\sqrt{k} расходится) - \sum \alpha_k^2 = c^2 \sum 1/(k+1) = \infty — условие НЕ выполняется!

Для выполнения обоих условий нужны разные убывающие шаги, например: \alpha_k = c/k даёт \sum \alpha_k = +\infty (гармонический ряд), \sum \alpha_k^2 = c^2\sum 1/k^2 < \infty. ✓

Смысл условий: - \sum \alpha_k = \infty: метод может дойти до любой точки (достаточно «дальнобойный») - \sum \alpha_k^2 < \infty: накопленный шум убывает → сходимость в пределе

б) Подставим \alpha_k = (f(w_k) - f^*)/\|g_k\|^2 в неравенство из Задачи 3: \begin{align*} \|w_{k+1} - w^*\|^2 &\leq \|w_k - w^*\|^2 - 2\alpha_k(f(w_k) - f^*) + \alpha_k^2\|g_k\|^2 \\ &= \|w_k - w^*\|^2 - \frac{2(f(w_k)-f^*)^2}{\|g_k\|^2} + \frac{(f(w_k)-f^*)^2}{\|g_k\|^4}\cdot\|g_k\|^2 \\ &= \|w_k - w^*\|^2 - \frac{(f(w_k)-f^*)^2}{\|g_k\|^2}. \end{align*}

Так как (f(w_k)-f^*)^2/\|g_k\|^2 \geq 0, расстояние строго убывает при f(w_k) > f^*. \square
