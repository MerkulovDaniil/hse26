Задача 1 (5 баллов)

Полные условия КТТ

Рассмотрим задачу: \min_{x \in \mathbb{R}^n} f(x) \quad \text{s.t.} \quad g_i(x) \leq 0,\ i = 1,\ldots,m; \quad h_j(x) = 0,\ j = 1,\ldots,p, где f, g_i — дифференцируемые функции.

а) (3 балла) Запишите полные условия КТТ (необходимые для локального минимума при выполнении условия регулярности LICQ).

б) (2 балла) Что такое условие дополняющей нежёсткости (complementary slackness)? Объясните его геометрический смысл.

Ответ

а) Функция Лагранжа: \mathcal{L}(x, \lambda, \nu) = f(x) + \sum_{i=1}^m \lambda_i g_i(x) + \sum_{j=1}^p \nu_j h_j(x).

Условия КТТ (необходимые, при LICQ): 1. Стационарность: \nabla_x \mathcal{L}(x^*, \lambda^*, \nu^*) = 0 2. Допустимость примала: g_i(x^*) \leq 0, h_j(x^*) = 0 3. Допустимость дуала: \lambda_i^* \geq 0 4. Дополняющая нежёсткость: \lambda_i^* g_i(x^*) = 0 для всех i

б) Условие \lambda_i^* g_i(x^*) = 0 означает: либо ограничение активно (g_i(x^*) = 0, и тогда \lambda_i^* \geq 0 может быть ненулевым), либо неактивно (g_i(x^*) < 0, и тогда \lambda_i^* = 0).

Геометрический смысл: неактивные ограничения не влияют на оптимальное решение — в окрестности x^* они не «давят».

Задача 2 (4 балла)

Простая задача с ограничением-неравенством

Найдите минимум f(x, y) = x^2 + y^2 при ограничениях: x + y \geq 2, \quad x \geq 0, \quad y \geq 0.

(Перепишите в стандартный вид g_i \leq 0, запишите КТТ, найдите решение.)

Ответ

Стандартный вид: g_1 = 2 - x - y \leq 0, g_2 = -x \leq 0, g_3 = -y \leq 0.

Лагранжиан: \mathcal{L} = x^2 + y^2 + \lambda_1(2 - x - y) - \lambda_2 x - \lambda_3 y.

КТТ: 2x - \lambda_1 - \lambda_2 = 0, \quad 2y - \lambda_1 - \lambda_3 = 0, \lambda_i \geq 0,\quad g_i \leq 0, \quad \lambda_i g_i = 0.

Проверим симметрию: попробуем x^* = y^* = 1.

  • g_1 = 2 - 1 - 1 = 0 → активно, \lambda_1 \geq 0
  • g_2 = -1 < 0 → \lambda_2 = 0; g_3 = -1 < 0 → \lambda_3 = 0

Стационарность: 2 \cdot 1 - \lambda_1 = 0 → \lambda_1 = 2 > 0. ✓

Ответ: x^* = y^* = 1, f^* = 2.

Задача 3 (5 баллов)

LASSO регрессия

Рассмотрим задачу: \min_{w \in \mathbb{R}^d} \frac{1}{2n}\|Xw - y\|^2 \quad \text{s.t.} \quad \|w\|_1 \leq t.

а) (2 балла) Запишите задачу в стандартном форме (с помощью вспомогательных переменных z_j = w_j и ограничений w_j \leq z_j, -w_j \leq z_j, \sum z_j \leq t). Каков порядок размерности переменных и ограничений?

б) (3 балла) Покажите, что задача LASSO с регуляризацией \min_{w} \frac{1}{2n}\|Xw - y\|^2 + \lambda \|w\|_1 эквивалентна задаче с ограничением при соответствующем выборе t = t(\lambda).

Ответ

а) Введём z_j \geq 0 для j = 1,\ldots,d. Ограничения \ell_1-шара: w_j \leq z_j,\quad -w_j \leq z_j,\quad \sum_{j=1}^d z_j \leq t.

Переменных: w \in \mathbb{R}^d, z \in \mathbb{R}^d → 2d переменных. Ограничений: 2d (для z) + 1 (\ell_1-шар) = 2d+1 неравенств.

б) По теореме о дополняющей нежёсткости, для задачи с ограничением при оптимуме (w^*, z^*): если ограничение \|w^*\|_1 \leq t активно, то \lambda^* > 0 — множитель Лагранжа.

Лагранжиан с ограничением-шаром: \frac{1}{2n}\|Xw - y\|^2 + \lambda^*(\|w\|_1 - t).

Это в точности задача с регуляризацией LASSO с \lambda = \lambda^* (минус константа \lambda^* t). Значит: для каждого \lambda > 0 существует t(\lambda) такое, что решения совпадают. Обратное: для каждого t — \lambda(t).

Задача 4 (5 баллов)

Двойственная задача и двойственный зазор

Дана задача: p^* = \min_{x \in \mathbb{R}} x^2 \quad \text{s.t.} \quad x \geq 1.

а) (3 балла) Постройте двойственную задачу через функцию Лагранжа \mathcal{L}(x, \lambda): - запишите \inf_x \mathcal{L}(x, \lambda) как функцию от \lambda \geq 0, - сформулируйте двойственную задачу d^* = \max_{\lambda \geq 0} g(\lambda).

б) (2 балла) Найдите p^* и d^*. Есть ли двойственный зазор? Выполняется ли сильная двойственность?

Ответ

а) Стандартный вид: g(x) = 1 - x \leq 0. Лагранжиан: \mathcal{L}(x, \lambda) = x^2 + \lambda(1 - x) = x^2 - \lambda x + \lambda.

Минимум по x: \frac{\partial \mathcal{L}}{\partial x} = 2x - \lambda = 0 → x^* = \lambda/2.

Двойственная функция: g(\lambda) = \inf_x \mathcal{L}(x, \lambda) = \frac{\lambda^2}{4} - \frac{\lambda^2}{2} + \lambda = \lambda - \frac{\lambda^2}{4}.

Двойственная задача: \max_{\lambda \geq 0}\, \lambda - \frac{\lambda^2}{4}.

б) Оптимум примала: x^* = 1 (граница), p^* = 1.

Оптимум дуала: \frac{d}{d\lambda}(λ - λ^2/4) = 1 - λ/2 = 0 → \lambda^* = 2. d^* = 2 - 1 = 1.

p^* = d^* = 1 → зазора нет, сильная двойственность выполняется.

(Slater: допустимое множество \{x \geq 1\} строго непусто — внутренняя точка x = 2 > 1. По условию Слейтера сильная двойственность ✓.)

Задача 5 (5 баллов)

Условие Слейтера и сильная двойственность

а) (2 балла) Сформулируйте условие Слейтера для задачи с выпуклыми неравенствами и аффинными равенствами. Что оно гарантирует?

б) (3 балла) Рассмотрим задачу: \min_{x \in \mathbb{R}^2} x_1 + x_2 \quad \text{s.t.} \quad x_1^2 + x_2^2 \leq 1, \quad x_1 + x_2 \geq 0. Выполняется ли условие Слейтера? Запишите КТТ. Найдите оптимальное решение.

Ответ

а) Условие Слейтера: существует строго допустимая точка \tilde{x} такая, что g_i(\tilde{x}) < 0 для всех i = 1,\ldots,m, и h_j(\tilde{x}) = 0.

Гарантирует: при выпуклой задаче — сильную двойственность (p^* = d^*) и допустимость двойственной задачи.

б) Стандартный вид: g_1 = x_1^2 + x_2^2 - 1 \leq 0, g_2 = -x_1 - x_2 \leq 0.

Slater: возьмём \tilde{x} = (0.1, 0.1): g_1 = 0.02 - 1 < 0 ✓, g_2 = -0.2 < 0 ✓. Условие Слейтера выполнено.

КТТ (с \lambda_1, \lambda_2 \geq 0): 1 + 2\lambda_1 x_1 - \lambda_2 = 0, \quad 1 + 2\lambda_1 x_2 - \lambda_2 = 0, \lambda_1(x_1^2 + x_2^2 - 1) = 0, \quad \lambda_2(-x_1 - x_2) = 0.

Из первых двух уравнений: x_1 = x_2.

Минимум линейной функции на круге при x_1 = x_2: направление убывания f = x_1 + x_2 — в сторону (-1, -1). Ограничение x_1 + x_2 \geq 0: при x_1 = x_2 \geq 0, точка x_1 = x_2 = 0, но g_2(0,0) = 0 — активно.

Проверка: при x^* = (0, 0): g_1 = -1 < 0 → \lambda_1 = 0; g_2 = 0 → \lambda_2 \geq 0.

Стационарность: 1 - \lambda_2 = 0 → \lambda_2 = 1 > 0. ✓

Ответ: x^* = (0, 0), f^* = 0.

Задача 6 (5 баллов)

Седловая точка и КТТ

Покажите, что если (x^*, \lambda^*, \nu^*) — седловая точка функции Лагранжа: \mathcal{L}(x^*, \lambda, \nu) \leq \mathcal{L}(x^*, \lambda^*, \nu^*) \leq \mathcal{L}(x, \lambda^*, \nu^*) для всех x, \lambda \geq 0, \nu, то x^* — оптимум примала и выполнена сильная двойственность (p^* = d^*).

Ответ

Шаг 1: Из правого неравенства \mathcal{L}(x^*, \lambda^*, \nu^*) \leq \mathcal{L}(x, \lambda^*, \nu^*) для всех x: x^* — минимизатор \mathcal{L}(x, \lambda^*, \nu^*). Значит \nabla_x \mathcal{L}(x^*, \lambda^*, \nu^*) = 0 (стационарность КТТ).

Шаг 2: Из левого неравенства \mathcal{L}(x^*, \lambda, \nu) \leq \mathcal{L}(x^*, \lambda^*, \nu^*) для всех \lambda \geq 0: f(x^*) + \lambda^T g(x^*) + \nu^T h(x^*) \leq f(x^*) + {\lambda^*}^T g(x^*) + {\nu^*}^T h(x^*) для всех \lambda \geq 0. При \lambda \to +\infty в одном компоненте: g_i(x^*) \leq 0 — допустимость.

При \lambda = 0: f(x^*) + \nu^T h(x^*) \leq \mathcal{L}(x^*, \lambda^*, \nu^*), откуда h(x^*) = 0 (иначе в левой части можно сделать $> $ правой).

Дополняющая нежёсткость: максимум по \lambda достигается при \lambda^*_i g_i(x^*) = 0.

Итого: \mathcal{L}(x^*, \lambda^*, \nu^*) = f(x^*) (т.к. g_i(x^*) \leq 0, \lambda^*_i g_i(x^*) = 0, h_j(x^*) = 0). Следовательно: d^* \geq g(\lambda^*, \nu^*) = \inf_x \mathcal{L}(x, \lambda^*, \nu^*) \geq \mathcal{L}(x^*, \lambda^*, \nu^*) = f(x^*) = p^*.

Но всегда d^* \leq p^* (слабая двойственность). Значит d^* = p^*. \square

Задача 7 (6 баллов)

Геометрическая интерпретация КТТ

а) (3 балла) Пусть f, g_i — выпуклые гладкие функции, задача выпуклая. При выполнении условия Слейтера точка x^* оптимальна тогда и только тогда, когда выполнены условия КТТ. Объясните (без строгого доказательства) геометрический смысл: почему -\nabla f(x^*) лежит в конусе \{- \sum_i \lambda_i \nabla g_i(x^*) : \lambda_i \geq 0\}?

б) (3 балла) Рассмотрим задачу: \min_{x \in \mathbb{R}^2}\, c^T x \quad \text{s.t.} \quad Ax \leq b, где c \in \mathbb{R}^2, A \in \mathbb{R}^{m \times 2}, b \in \mathbb{R}^m — задача линейного программирования.

Запишите двойственную задачу и сформулируйте теорему о сильной двойственности для LP.

Ответ

а) В точке x^* направление убывания f — вектор -\nabla f(x^*). Если x^* лежит на границе допустимой области (активные ограничения), то двигаться в направлении -\nabla f(x^*) нельзя — нарушится допустимость. Это значит, что -\nabla f(x^*) не является допустимым направлением, т.е. он «направлен внутрь» конуса нормалей \nabla g_i(x^*).

Формально: \nabla f(x^*) + \sum_{i: g_i(x^*)=0} \lambda_i \nabla g_i(x^*) = 0 — вектор \nabla f(x^*) «уравновешивается» градиентами активных ограничений с неотрицательными весами \lambda_i.

б) Лагранжиан: \mathcal{L}(x, \lambda) = c^T x + \lambda^T(Ax - b) = (A^T\lambda + c)^T x - \lambda^T b.

Двойственная функция: g(\lambda) = \inf_x (A^T\lambda + c)^T x - \lambda^T b = \begin{cases} -\lambda^T b, & \text{если } A^T\lambda + c = 0 \\ -\infty, & \text{иначе.} \end{cases}

Двойственная задача LP: \max_{\lambda \geq 0}\, {-b^T\lambda} \quad \text{s.t.} \quad A^T\lambda + c = 0, или в стандартном виде: \max_{\lambda \geq 0}\, {-b^T\lambda} при A^T\lambda = -c.

Теорема о сильной двойственности для LP: если примальная задача LP допустима и ограничена, то p^* = d^*, и обе задачи (примальная и двойственная) достигают оптимума.
