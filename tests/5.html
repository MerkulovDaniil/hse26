Курс: Алгоритмы оптимизации, ВШЭ ФКН, весна 2026 Тема: Критерии сильной выпуклости; условия первого и второго порядка (КТТ-lite) Формат: 7 задач; 60 минут; закрытые книги Максимум: 35 баллов

Задача 1 (4 балла)

Критерий сильной выпуклости

Функция f : \mathbb{R}^n \to \mathbb{R} называется \mu-сильно выпуклой, если для всех x, y и t \in [0,1]:

f(tx + (1-t)y) \leq tf(x) + (1-t)f(y) - \frac{\mu}{2}t(1-t)\|x-y\|^2.

а) (2 балла) Покажите, что функция f(x) = \frac{1}{2}x^T A x + b^T x + c, где A \succ 0 — симметричная положительно определённая матрица, является сильно выпуклой. Найдите константу \mu.

б) (2 балла) Является ли f(x) = x^4 сильно выпуклой на \mathbb{R}? На [-1, 1]? Обоснуйте.

Ответ

а) \nabla^2 f(x) = A — константа. По критерию \nabla^2 f(x) \succeq \mu I сильная выпуклость следует с \mu = \lambda_{\min}(A) > 0 (т.к. A \succ 0).

б) На \mathbb{R}: нет. f''(x) = 12x^2 \geq 0 но \inf_{x \in \mathbb{R}} f''(x) = 0 (при x \to 0), значит нет \mu > 0 такого что f''(x) \geq \mu всюду. На [-1,1]: f''(x) = 12x^2 \geq 0, но f''(0) = 0, значит тоже не сильно выпуклая.

Задача 2 (5 баллов)

Единственность минимума сильно выпуклой функции

Докажите, что у сильно выпуклой (с константой \mu > 0) функции на \mathbb{R}^n существует не более одного глобального минимума.

Указание: Предположите от противного, что x^* и y^* — два различных минимума. Используйте определение сильной выпуклости.

Ответ

Пусть x^* и y^* — два глобальных минимума, x^* \neq y^*. По определению f(x^*) = f(y^*) = f^*. Подставим t = 1/2:

f\!\left(\frac{x^*+y^*}{2}\right) \leq \frac{1}{2}f(x^*) + \frac{1}{2}f(y^*) - \frac{\mu}{8}\|x^*-y^*\|^2 = f^* - \frac{\mu}{8}\|x^*-y^*\|^2 < f^*.

Но f^* — глобальный минимум, противоречие. \square

Задача 3 (5 баллов)

Скорость сходимости градиентного спуска

Для \mu-сильно выпуклой L-гладкой функции метод градиентного спуска с шагом \alpha = 1/L даёт:

f(x_k) - f(x^*) \leq \left(1 - \frac{\mu}{L}\right)^k (f(x_0) - f(x^*)).

а) (2 балла) Пусть f(x) = \frac{1}{2}\|Ax - b\|^2, A \in \mathbb{R}^{m \times n}, A^T A \succ 0. Найдите \mu и L через сингулярные числа A.

б) (3 балла) Число обусловленности \kappa = L/\mu. Сколько итераций нужно для достижения f(x_k) - f^* \leq \varepsilon при начальном зазоре f(x_0) - f^* = \Delta? Выразите ответ через \kappa, \Delta, \varepsilon.

Ответ

а) f(x) = \frac{1}{2}x^T A^T A x - b^T A x + \frac{1}{2}\|b\|^2. Гессиан: \nabla^2 f = A^T A. Значит: - \mu = \lambda_{\min}(A^T A) = \sigma_{\min}^2(A) - L = \lambda_{\max}(A^T A) = \sigma_{\max}^2(A) - \kappa = \sigma_{\max}^2 / \sigma_{\min}^2

б) Нужно (1 - 1/\kappa)^k \leq \varepsilon / \Delta. Взяв логарифм: k \geq \frac{\ln(\Delta/\varepsilon)}{\ln(1/(1-1/\kappa))} \approx \kappa \ln\frac{\Delta}{\varepsilon}, поскольку \ln(1/(1-1/\kappa)) \approx 1/\kappa при большом \kappa. Итого: k = O(\kappa \log(1/\varepsilon)).

Задача 4 (5 баллов)

Условия первого порядка (необходимые)

Рассмотрим задачу: \min_{x \in \mathbb{R}^n} f(x), \quad \text{где } f \text{ дифференцируема.}

а) (2 балла) Сформулируйте необходимое условие локального минимума в терминах \nabla f(x^*).

б) (3 балла) Является ли это условие достаточным? Приведите пример функции, где \nabla f(x^*) = 0, но x^* — не минимум, не максимум, а седловая точка. Нарисуйте эскиз.

Ответ

а) Необходимое условие: если x^* — локальный минимум f, то \nabla f(x^*) = 0.

б) Нет, не достаточное. Пример: f(x, y) = x^2 - y^2 (или f(x, y) = xy). В точке (0, 0): \nabla f = (0, 0), но это седловая точка — вдоль x-оси минимум, вдоль y-оси максимум. Эскиз: поверхность «седло лошади».

Задача 5 (6 баллов)

Условия второго порядка

Пусть f : \mathbb{R}^n \to \mathbb{R} — дважды дифференцируема, \nabla f(x^*) = 0.

а) (2 балла) Сформулируйте достаточное условие локального минимума через \nabla^2 f(x^*).

б) (2 балла) Сформулируйте необходимое условие локального минимума через \nabla^2 f(x^*).

в) (2 балла) Найдите все стационарные точки f(x, y) = x^3 + y^3 - 3xy и определите их тип (минимум / максимум / седло).

Ответ

а) Достаточное: \nabla^2 f(x^*) \succ 0 (строго положительно определён) ⇒ x^* — строгий локальный минимум.

б) Необходимое: \nabla^2 f(x^*) \succeq 0 (положительно полуопределён). Если \nabla^2 f(x^*) имеет хотя бы одно отрицательное собственное значение, x^* не является локальным минимумом.

в) Стационарные точки: \nabla f = (3x^2 - 3y, 3y^2 - 3x) = 0, т.е.: - x^2 = y, y^2 = x ⇒ x^4 = x ⇒ x(x^3 - 1) = 0 ⇒ x = 0 или x = 1. - Точки: (0, 0) и (1, 1).

Гессиан: H = \begin{pmatrix} 6x & -3 \\ -3 & 6y \end{pmatrix}

  • В (0,0): H = \begin{pmatrix} 0 & -3 \\ -3 & 0 \end{pmatrix}, собственные значения \pm 3 → седловая точка.
  • В (1,1): H = \begin{pmatrix} 6 & -3 \\ -3 & 6 \end{pmatrix}, \det H = 36-9=27 > 0, tr H = 12 > 0 → локальный минимум.

Задача 6 (5 баллов)

КТТ условия (упрощённые, без двойственности)

Задача с ограничениями-равенствами: \min_{x \in \mathbb{R}^n} f(x) \quad \text{s.t.} \quad h(x) = 0, где h : \mathbb{R}^n \to \mathbb{R}^m.

Функция Лагранжа: \mathcal{L}(x, \nu) = f(x) + \nu^T h(x).

а) (2 балла) Запишите условия первого порядка (КТТ) для этой задачи.

б) (3 балла) Найдите минимум f(x,y) = x^2 + y^2 при ограничении x + y = 1.

Ответ

а) КТТ первого порядка: \nabla_x \mathcal{L}(x^*, \nu^*) = 0 \quad \Leftrightarrow \quad \nabla f(x^*) + J_h(x^*)^T \nu^* = 0, h(x^*) = 0.

б) \mathcal{L} = x^2 + y^2 + \nu(x+y-1).

КТТ: \partial_x \mathcal{L} = 2x + \nu = 0, \partial_y \mathcal{L} = 2y + \nu = 0, x + y = 1.

Из первых двух: x = y = -\nu/2. Подставляем: -\nu = 1, т.е. \nu = -1, x = y = 1/2.

Ответ: x^* = y^* = 1/2, f^* = 1/2.

Проверка: по симметрии и методу кругов Лагранжа это точка ближайшая к началу на прямой x+y=1 — очевидно (1/2, 1/2).

Задача 7 (5 баллов)

Сильная выпуклость и единственность решения в задаче с ограничениями

а) (2 балла) Пусть f — \mu-сильно выпуклая, C — выпуклое замкнутое множество. Докажите единственность решения задачи \min_{x \in C} f(x).

б) (3 балла) Рассмотрим задачу Ridge regression: \min_{w \in \mathbb{R}^d} \frac{1}{2n}\|Xw - y\|^2 + \frac{\lambda}{2}\|w\|^2, \quad \lambda > 0. Покажите, что функция сильно выпукла (найдите \mu), запишите КТТ, и найдите аналитическое решение.

Ответ

а) Предположим от противного: x^*, y^* \in C — два решения. Т.к. C выпуклое, z = (x^*+y^*)/2 \in C. Из сильной выпуклости: f(z) \leq \frac{1}{2}f(x^*) + \frac{1}{2}f(y^*) - \frac{\mu}{8}\|x^*-y^*\|^2 = f^* - \frac{\mu}{8}\|x^*-y^*\|^2 < f^*. Противоречие с тем, что f^* — минимальное значение на C. \square

б) Функция: \Phi(w) = \frac{1}{2n}w^T X^T X w - \frac{1}{n}y^T X w + \frac{1}{2n}\|y\|^2 + \frac{\lambda}{2}\|w\|^2.

Гессиан: \nabla^2 \Phi = \frac{1}{n}X^T X + \lambda I \succeq \lambda I.

Значит \Phi — \mu-сильно выпуклая с \mu = \lambda > 0.

КТТ (задача без ограничений, C = \mathbb{R}^d): \nabla \Phi(w^*) = 0: \frac{1}{n}X^T(Xw^* - y) + \lambda w^* = 0.

Решение: w^* = \left(\frac{X^T X}{n} + \lambda I\right)^{-1} \frac{X^T y}{n}.

Матрица (X^TX/n + \lambda I) обратима при любом \lambda > 0 (все собственные значения \geq \lambda).
