Задача 1 (5 баллов)

Метод тяжёлого шара (Heavy Ball)

Рассмотрим задачу минимизации f(x) = \tfrac{1}{2}x^\top A x - b^\top x, где A \succ 0, собственные значения 0 < \mu \leq \lambda_1 \leq \dots \leq \lambda_n \leq L.

а) (3 балла) Запишите итерацию метода тяжёлого шара Полиака (Heavy Ball): x_{k+1} = x_k - \alpha\nabla f(x_k) + \beta(x_k - x_{k-1}) Покажите, что при оптимальных параметрах \alpha^* = \dfrac{4}{(\sqrt{L}+\sqrt{\mu})^2} и \beta^* = \left(\dfrac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\right)^2 скорость сходимости: \|x_k - x^*\| \leq C\cdot\left(\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\right)^k, где \kappa = L/\mu. Подсказка: перепишите двухшаговую итерацию как одношаговую для (x_k - x^*, x_{k-1} - x^*)^\top.

б) (2 балла) Сравните с GD (без момента): скорость GD — \left(\dfrac{\kappa-1}{\kappa+1}\right)^k. Для \kappa = 100: на сколько порядков Heavy Ball быстрее GD при k = 100?

Ответ

а) Сделаем замену e_k = x_k - x^*. Итерация в терминах ошибки: e_{k+1} = e_k - \alpha A e_k + \beta(e_k - e_{k-1}) = (I - \alpha A + \beta I)e_k - \beta e_{k-1}. В собственном базисе A (eigenvalue \lambda_i): (e_{k+1})_i = (1 - \alpha\lambda_i + \beta)(e_k)_i - \beta(e_{k-1})_i. Характеристический многочлен: t^2 - (1 - \alpha\lambda_i + \beta)t + \beta = 0. Корни: t_{1,2} = \dfrac{(1-\alpha\lambda_i+\beta) \pm \sqrt{(1-\alpha\lambda_i+\beta)^2 - 4\beta}}{2}.

Оптимальные параметры обеспечивают двойной корень t = \sqrt{\beta} для \lambda_i = \sqrt{L\mu} (среднегеометрического), откуда: \alpha^* = \frac{4}{(\sqrt{L}+\sqrt{\mu})^2}, \qquad \beta^* = \left(\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\right)^2. При этом |t| = \sqrt{\beta^*} = \dfrac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1} для всех \lambda_i \in [\mu, L], и \|e_k\| \leq C \cdot \left(\dfrac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\right)^k.

б) GD-скорость: r_{\mathrm{GD}} = \dfrac{99}{101} \approx 0.980. HB-скорость: r_{\mathrm{HB}} = \dfrac{9}{11} \approx 0.818. При k=100: GD — 0.980^{100} \approx 0.135; HB — 0.818^{100} \approx 7 \times 10^{-9}. HB примерно в 10^7 раз точнее!

Задача 2 (5 баллов)

Алгоритм Нестерова (AGD) для гладких функций

Для L-гладкой выпуклой функции f метод Нестерова (AGD): y_{k+1} = x_k - \frac{1}{L}\nabla f(x_k), \qquad x_{k+1} = y_{k+1} + \frac{t_k - 1}{t_{k+1}}(y_{k+1} - y_k), где t_1 = 1 и t_{k+1} = \dfrac{1 + \sqrt{1 + 4t_k^2}}{2}.

а) (2 балла) Вычислите t_1, t_2, t_3, t_4 и докажите, что t_k \geq \dfrac{k+1}{2}.

б) (3 балла) Сформулируйте оценку сходимости: f(y_k) - f^* \leq \frac{2L\|x_0 - x^*\|^2}{(k+1)^2}. Поясните, почему это O(1/k^2), а не O(1/k) как у GD.

Ответ

а) Вычисление: - t_1 = 1 - t_2 = (1 + \sqrt{1+4})/2 = (1+\sqrt{5})/2 \approx 1.618 - t_3 = (1+\sqrt{1+4\cdot(1.618)^2})/2 = (1+\sqrt{1+10.47})/2 \approx (1+3.387)/2 \approx 2.193 - t_4 \approx (1+\sqrt{1+4\cdot(2.193)^2})/2 \approx (1+\sqrt{20.24})/2 \approx (1+4.499)/2 \approx 2.749

Доказательство t_k \geq (k+1)/2 по индукции: - t_1 = 1 = 2/2 \geq 1 ✓ - Если t_k \geq (k+1)/2, то t_{k+1} = (1+\sqrt{1+4t_k^2})/2 \geq (1+\sqrt{1+(k+1)^2})/2 \geq (1+k+1)/2 = (k+2)/2 ✓ (используя \sqrt{1+(k+1)^2} \geq k+1 для k \geq 1).

б) Ключевое: AGD поддерживает Lyapunov-функцию \Phi_k = t_k^2(f(y_k) - f^*) + \frac{L}{2}\|t_k(y_k - x^*) - (t_k - 1)(y_{k-1}-x^*)\|^2 \leq \Phi_{k-1}. Это убывающая последовательность (доказывается descent lemma для L-гладких функций). Начальное значение \Phi_0 \leq L/2\|x_0-x^*\|^2. Из t_k^2 \geq (k+1)^2/4: f(y_k) - f^* \leq \frac{\Phi_0}{t_k^2} \leq \frac{L/2\|x_0-x^*\|^2}{(k+1)^2/4} = \frac{2L\|x_0-x^*\|^2}{(k+1)^2}.

GD: f(y_k) - f^* \leq \dfrac{L\|x_0-x^*\|^2}{2k} (O(1/k)). AGD добавляет «память» (x_k \neq y_k) — момент из прошлых шагов, что обеспечивает O(1/k^2).

Задача 3 (5 баллов)

Сравнение GD и AGD: числовой пример

Функция f(x_1, x_2) = \tfrac{1}{2}(x_1^2 + 100x_2^2) с минимумом x^* = 0. Здесь \mu = 1, L = 100, \kappa = 100.

а) (2 балла) Сколько итераций GD нужно для \|x_k - x^*\| \leq 10^{-4}\|x_0 - x^*\|? Шаг \alpha = 1/L.

б) (2 балла) Сколько итераций AGD нужно для той же точности?

в) (1 балл) Во сколько раз AGD быстрее? Имеет ли смысл ускорение при \kappa = 2?

Ответ

а) GD-скорость: r = (1 - \mu/L) = 0.99. Нужно r^k \leq 10^{-4}: k \geq \frac{4\ln 10}{-\ln 0.99} \approx \frac{9.21}{0.01005} \approx 916 \text{ итераций.}

б) AGD: f(y_k) - f^* \leq \dfrac{2L\|x_0\|^2}{(k+1)^2} \leq \dfrac{200\|x_0\|^2}{(k+1)^2}. Из \|x_k - x^*\|^2 \leq 2(f(x_k)-f^*)/\mu: хотим \|x_k\|/\|x_0\| \leq 10^{-4}, т.е. \|x_k\|^2/\|x_0\|^2 \leq 10^{-8}. Нужно 400/(k+1)^2 \leq 10^{-8}, т.е. (k+1) \geq 2\times10^5.

На самом деле для сильно выпуклого случая AGD имеет скорость \left(\dfrac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\right)^k \approx 0.818^k. Тогда 0.818^k \leq 10^{-4} → k \geq 4\ln10/(-\ln 0.818) \approx 9.21/0.2009 \approx 46 итераций.

в) AGD быстрее в 916/46 \approx 20 раз (\approx\sqrt{\kappa}). При \kappa = 2: GD-скорость 1/3, AGD (\sqrt{2}-1)/(\sqrt{2}+1) \approx 0.172. Ускорение: \frac{\log(1/3)}{\log(1/0.172)} \approx \frac{1.1}{1.76} \approx 0.6 — AGD лишь немного быстрее. При малом \kappa ускорение незначительно.

Задача 4 (5 баллов)

FISTA (Fast ISTA) для негладких задач

Задача: \min_{x} f(x) + g(x), где f — L-гладкая выпуклая, g — выпуклая (возможно, негладкая).

а) (3 балла) Запишите алгоритм FISTA (Beck–Teboulle, 2009). Чем он отличается от ISTA? Как выбрать шаг? Докажите скорость O(1/k^2) для функциональной ошибки.

б) (2 балла) Для задачи Lasso \min_x \tfrac{1}{2}\|Ax-b\|^2 + \lambda\|x\|_1: как конкретно выглядят шаги FISTA? Чему равен \mathrm{prox}_{h\lambda\|\cdot\|_1}?

Ответ

а) FISTA: y_{k+1} = \mathrm{prox}_{h g}\!\left(x_k - h\nabla f(x_k)\right), \qquad x_{k+1} = y_{k+1} + \frac{t_k-1}{t_{k+1}}(y_{k+1} - y_k), с t_1=1, t_{k+1} = (1+\sqrt{1+4t_k^2})/2. Шаг h = 1/L.

Отличие от ISTA: ISTA — y_{k+1} = \mathrm{prox}_{hg}(y_k - h\nabla f(y_k)) (без момента). FISTA добавляет момент Нестерова: x_k — «ускоренная» точка, от которой делается шаг.

Скорость FISTA: из той же Lyapunov-функции \Phi_k = t_k^2(F(y_k)-F^*) + \|v_k\|^2/(2h), F(y_k) - F^* \leq \frac{2\|x_0-x^*\|^2}{hk^2} = \frac{2L\|x_0-x^*\|^2}{k^2}.

Шаг: h \leq 1/L. При h = 1/L: одно вычисление градиента \nabla f + один прокс-шаг за итерацию.

б) FISTA для Lasso (f(x) = \tfrac{1}{2}\|Ax-b\|^2, g(x) = \lambda\|x\|_1): u_k = x_k - \frac{1}{L}A^\top(Ax_k - b), \qquad y_{k+1} = \mathcal{S}_{\lambda/L}(u_k), \qquad x_{k+1} = y_{k+1} + \frac{t_k-1}{t_{k+1}}(y_{k+1}-y_k).

Прокс-оператор: \mathrm{prox}_{h\lambda\|\cdot\|_1}(u) = \mathcal{S}_{h\lambda}(u) — мягкое пороговое: [\mathcal{S}_{h\lambda}(u)]_i = \mathrm{sign}(u_i)\max(|u_i| - h\lambda, 0).

Задача 5 (5 баллов)

Нижние оценки сложности

а) (3 балла) Докажите, что для любого алгоритма «первого порядка», использующего лишь значения f(x_0), \nabla f(x_0), \dots, f(x_{k-1}), \nabla f(x_{k-1}): \min_{0 \leq i \leq k-1}f(x_i) - f^* \geq \frac{3L\|x_0-x^*\|^2}{32(k+1)^2}. Подсказка: рассмотрите «лестничную функцию» f_k(x) = \dfrac{L}{8}\left(\|x\|^2 - \dfrac{k}{k+1}e_1^\top x\right) на \R^k.

б) (2 балла) Какой вывод следует из нижней оценки и результата AGD (O(1/k^2))? Является ли AGD оптимальным?

Ответ

а) Конструкция Нестерова: на функции «лестничного» вида алгоритм первого порядка «не видит» компоненты x_{i+1}, \dots, x_d до i-й итерации. Точнее, если x_0 = 0 и алгоритм работает в линейном подпространстве \mathrm{span}\{\nabla f(x_0), \dots, \nabla f(x_{k-1})\}, то для специальной функции f (трёхдиагональный квадратичный функционал) имеем: f(x_{k-1}) - f^* \geq \frac{\mu(d-k+1)}{2(d+1)}\left(\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\right)^{2(k-1)}\|x_0-x^*\|^2, что при \mu \to 0 (выпуклый случай) даёт O(1/k^2) как нижнюю оценку.

Для L-гладкой (не сильно) выпуклой функции: нижняя оценка O(L\|x_0-x^*\|^2/k^2).

б) AGD достигает O(L\|x_0-x^*\|^2/k^2) — в точности нижняя оценка (с точностью до константы). AGD является оптимальным в классе алгоритмов первого порядка для L-гладких выпуклых функций! Значит, O(1/k^2) — лучшее, чего можно достичь без дополнительных предположений (сильная выпуклость, структура Гессиана и т.п.).

Задача 6 (5 баллов)

Ускорение для сильно выпуклых функций

Для \mu-сильно выпуклой L-гладкой функции (\kappa = L/\mu).

а) (2 балла) Запишите алгоритм FISTA с перезапуском (restarted FISTA): каждые T = O(\sqrt{\kappa}) итераций сбрасываем момент (x \leftarrow y, t \leftarrow 1). Какова скорость сходимости?

б) (3 балла) Сравните скорости GD, AGD (гладкий выпуклый), AGD с перезапуском, HB:

Метод Гарантируемая скорость
GD \left(1-\tfrac{1}{\kappa}\right)^k
AGD (выпуклый) O\!\left(\dfrac{L\|x_0\|^2}{k^2}\right)
AGD с перезапуском e^{-k/\sqrt{\kappa}}
Heavy Ball \left(\dfrac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\right)^k

Для \kappa = 10^4 и k = 100: оцените каждую скорость численно.

Ответ

а) Restarted FISTA: запускаем FISTA с T = \lceil\sqrt{\kappa}\rceil итерациями. После каждого «эпизода»: f(y_T) - f^* \leq \dfrac{2L\|x_0-x^*\|^2}{T^2} \leq \dfrac{2(f(x_0)-f^*)}{\mu T^2/L} \cdot\mu\|x_0\|^2/\ldots

Точнее: после T = O(\sqrt{\kappa}) шагов FISTA f(y_T) - f^* \leq \dfrac{c}{\kappa}(f(x_0)-f^*). Через n перезапусков: (c/\kappa)^n — экспоненциальная скорость с e^{-n\log(\kappa/c)} \approx e^{-k/\sqrt{\kappa}}.

б) Для \kappa = 10^4, k = 100: - GD: (1 - 10^{-4})^{100} \approx 1 - 0.01 = 0.99 (практически нет сходимости!) - AGD (выпуклый): \sim 2L/(k^2\|x_0\|^2) — зависит от \|x_0\| (не экспоненциальная) - AGD с перезапуском: e^{-100/100} = e^{-1} \approx 0.368 (умеренно) - Heavy Ball: \left(\dfrac{100-1}{100+1}\right)^{100} = \left(\dfrac{99}{101}\right)^{100} \approx 0.136

При k = 1000: - GD: (0.9999)^{1000} \approx 0.905 — ужасно! - HB: (99/101)^{1000} \approx 7.5\times10^{-9} — отлично.

Задача 7 (5 баллов)

Ускорение в стохастическом случае

а) (3 балла) Пусть при каждом шаге AGD доступен только стохастический градиент g_k с \mathbb{E}[g_k] = \nabla f(x_k) и \mathbb{E}\|g_k - \nabla f(x_k)\|^2 \leq \sigma^2.

Рассмотрим «стохастический AGD»: y_{k+1} = x_k - \frac{1}{L}g_k, \qquad x_{k+1} = y_{k+1} + \frac{t_k-1}{t_{k+1}}(y_{k+1}-y_k).

Докажите (неформально), что стохастический шум «разрушает» ускорение. Какова оптимальная скорость стохастического алгоритма?

б) (2 балла) Почему SGD не ускоряется с помощью момента Нестерова (в отличие от GD)? Что будет, если просто добавить момент к SGD?

Ответ

а) Анализ: Lyapunov-функция AGD требует точного убывания \Phi_k \leq \Phi_{k-1}. Шум \xi_k = g_k - \nabla f(x_k) добавляет в \Phi_k случайный член O(\xi_k \cdot v_k). После k шагов накапливается дисперсия \sim k\sigma^2/L^2 — линейная в k.

Итого: \mathbb{E}[f(y_k) - f^*] \leq \dfrac{2L\|x_0-x^*\|^2}{k^2} + \dfrac{C\sigma^2 k}{L}. Минимум по k: при k \sim (L^3\|x_0\|^2/\sigma^2)^{1/3} получаем ошибку O(\sigma^{4/3}/L^{1/3}k^{2/3}).

Оптимальная скорость (Аgarwal et al., 2012): \mathbb{E}[f(x_k) - f^*] \geq \Omega\!\left(\frac{L\|x_0\|^2}{k^2} + \frac{\sigma\|x_0\|}{\sqrt{k}}\right). SGD достигает O(1/\sqrt{k}) — это оптимально в стохастическом случае.

б) В детерминированном случае момент Нестерова работает за счёт «корреляции» направлений: x_{k+1} - x_k в AGD «запоминает» накопленный прогресс. В стохастическом случае: 1. Шум некоррелирован между шагами → «память» момента накапливает ошибку. 2. Добавление большого момента к SGD: дисперсия градиентов умножается на (1/(1-\beta)^2) — вместо ускорения получаем замедление! 3. «Катастрофа момента»: при \beta \to 1 (сильный момент) ошибка SGD растёт как O(\sigma^2/(1-\beta)).

Вывод: для SGD оптимален убывающий шаг \alpha_k = O(1/\sqrt{k}) без момента (или с малым моментом \beta < 1/2).
